Review guide

Release candidates are verified against their immutable catalog and application receipts.

Content and rights

Catalog downloads contain descriptions, media, recognition rules, and Profiles. They contain no executable or native code and cannot download an emulator Core. RGM does not download or distribute third-party game binaries.

Catalog identity

The app verifies exact catalog index bytes with its pinned Ed25519 key, verifies each object by size and SHA-256, and activates the result atomically.
