Review guide

A direct path through the signed demo catalog and the rights-cleared game shown in the store listing.

Network is required on first launch. RGM verifies and caches the signed demo catalog. Later launches can use the last verified copy offline.

Install the demo game

  1. Launch RGM with internet access and wait for Three in a Row to appear.
  2. Download the DOS package and extract it with the device's Files app.
  3. Open Three in a Row in RGM, choose Install, and select the extracted folder.
  4. After local recognition completes, choose Play.

Controls to verify

  • Tap an empty board cell to place an X.
  • Use the arrow keys and Enter when a hardware keyboard is available.
  • Open Help with F1, or use the on-screen Help control.
  • Finish a round and start another; the match ledger persists locally.

Content and rights

Three in a Row is first-party software by The Funky Bits, published under the MIT License. Its executable, source, checksums, and provenance are available from the immutable artifact page. RGM does not download or distribute third-party game binaries.

Catalog identity

The default endpoint is https://thefunkybits.github.io/rgm/catalogs/v2/demo/index.json. The app verifies the exact index bytes with its pinned Ed25519 key, verifies each object by size and SHA-256, and activates the result atomically.
