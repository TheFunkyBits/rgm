Privacy policy

Summary

Retro Games Mobile is provided by The Funky Bits. The Android application dev.thefunkybits.rgm does not collect, sell, or share personal data. It has no account system, analytics, advertising, cloud synchronization, or application-operated server.

Catalog network requests

RGM uses the internet to retrieve public catalog indexes, detached signatures, adaptation Profiles, recognition rules, and catalog media over HTTPS. The default catalog is hosted on GitHub Pages. You may enter any public HTTPS transport URL, but RGM activates only catalogs whose exact index bytes verify under a global RGM public key pinned in the app.

The operator of any catalog host you choose may receive ordinary request information such as your IP address, request time, requested path, and RGM version in the user-agent string. RGM does not add an account identifier, advertising identifier, selected game files, installed content, saves, settings, or play history to these requests. GitHub describes its processing for the default host in the GitHub Privacy Statement.

Files you select

You choose a folder containing software files that you lawfully possess. Android grants the app read access to that selected location. RGM reads those files locally to identify a supported release and creates a private installation in the app's local storage. The selected and installed files are not uploaded by RGM.

The Android folder-access grant may remain until you revoke it in system settings, clear the app's data, or uninstall the app.

Local data, retention, and deletion

Verified catalog cache files, installed content, emulator configuration, local saves, settings, and play history remain on your device. RGM retains them until an applicable in-app removal or reset action, clearing app data, or uninstalling the app. RGM excludes its app-private data from Android backup and device transfer.

Security

Catalog transport requires HTTPS. Catalog indexes are verified with pinned Ed25519 public keys before any downloaded metadata or media becomes active. Catalog files are checked against signed SHA-256 sizes and hashes, then stored in Android app-private storage. The last verified catalog remains available offline.

Notifications

RGM may request Android notification permission so it can report the result of a local installation after you leave the app. The notification is generated on your device and contains no advertising or remote tracking.

Google Play

Google Play may process information independently when distributing the app, checking integrity, or reporting crashes according to Google's terms and privacy policy. RGM does not receive that information through an application analytics service.

This website

GitHub Pages hosts this static website and its catalog files. The site contains no RGM analytics, tracking scripts, forms, iframes, or remote media.

Children

RGM is not directed to children and does not knowingly collect information from anyone, including children.

Changes

If a later release changes data handling, this policy and applicable store disclosures will be updated before that behavior is distributed.
